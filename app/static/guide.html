中国大陆车辆需在 developer.tesla.cn 创建应用；其他地区使用 developer.tesla.com。接入设置仅限管理员。

控制指令如何发送

面板把控制指令交给服务器内的官方签名代理，由代理签名后发送给 Tesla。客户端密钥和授权令牌加密保存在服务器，签名私钥单独保存在服务器数据目录，浏览器不会读取这些密钥。

只有完成 Tesla 账号授权并在 Tesla App 中配对虚拟钥匙，车辆才会接受受保护的指令。页面中的“已确认配对”是你的确认记录，实际是否配对成功以 Tesla App 和指令结果为准。

使用已有托管服务

原有 CONTROL_API_URL 和 CONTROL_API_TOKEN 配置仍受支持。使用托管服务时，请按服务商指引配置回调和配对，不要把客户端密钥当成 API Token。完成自建接入后，面板优先使用自建代理。

常见问题

注册失败：检查应用是否获批、车辆地区、允许的源 URL 和公开公钥是否正确。授权失败：检查重定向 URI 完全一致，并在同一浏览器重新开始授权。

控制失败：检查虚拟钥匙、车辆是否在线，以及应用的车辆控制和充电权限。唤醒后可能需要稍等再发送指令。只读账号无法发送控制指令。

Fleet API 费用以 Tesla 开发者后台为准。建议先在车辆附近手动测试闪灯；解锁和打开行李箱等操作前请确认周围环境。
