检测中…

  1. 部署一体化服务

    TeslaMate、数据库与 TESLA Home 面板已在运行(本页能打开即说明部署成功)。

  2. 获取 Tesla 令牌

    TeslaMate 使用 Tesla 官方 API 令牌连接你的车辆。任选一种方式生成令牌 (用 Tesla 账号登录后,复制 Access Token 和 Refresh Token):
    📱 iPhone / Mac:App Store 安装「Auth app for Tesla」
    💻 Windows / macOS / Linux:GitHub 下载「Tesla Auth」 (github.com/adriankumpf/tesla_auth)
    令牌仅保存在你自己的服务器上(加密存储),不会上传到任何第三方。

  3. 在 TeslaMate 粘贴令牌

    打开 TeslaMate 管理页 (),在登录页粘贴两个令牌并保存。
    公网服务器上管理页默认只监听本机,请先在本地终端建立隧道再访问: (局域网/家庭服务器可把 .env 的 TESLAMATE_BIND 改为 0.0.0.0)

  4. 识别车辆

    TeslaMate 会自动连接账号下的车辆,通常几秒内完成。

  5. 数据同步

    行驶、充电、哨兵等数据将持续累积;回到面板即可查看可视化报表。
